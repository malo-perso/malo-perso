## Deux projets pour découvrir mon travail

### Arcadia · Du Python à une borne d’arcade

**Projet personnel individuel · 2025–2026**

Concevoir une borne physique implique de faire fonctionner ensemble le logiciel, les commandes et les périphériques. Arcadia réunit ces dimensions dans un même projet.

- **Application :** développement de l’interface utilisateur et du système de gestion des parties.
- **Matériel :** intégration des boutons, de l’écran tactile, du monnayeur et d’une bande LED.
- **Données :** gestion des statistiques et administration du système.

`Python` `Raspberry Pi` `Linux` `SQLite` `Git`

### CineCanva · Une application pour suivre ses films, séries et animés

**Projet en binôme · 2025**

Une application mobile qui associe interface, backend et base de données en graphe, avec un hébergement sur Azure.

- **Mobile :** création de l’interface avec React Native et NativeWind.
- **Backend :** conception du backend Django et modélisation des données avec Neo4j.
- **Cloud :** déploiement et hébergement sur Azure, gestion du code source sur GitLab.

`React Native` `NativeWind` `Django` `Neo4j` `Azure` `GitLab`

<sub>Arcadia est en cours de développement ; son dépôt reste privé. CineCanva est destiné à être commercialisé ; son code reste également privé.</sub>
